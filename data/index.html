System Compatibility

This scale has been customized to automatically sync spool weights and create auto-gen spools with your local Bambuddy instance.

About this Firmware

Based on the FilaMan project, this firmware is designed to simplify filament spool management. Identify and weigh your spools automatically and keep your inventory synced with Bambuddy.

Spool Identification

Easily identify filament spools using NFC tags for instant tracking.

Automatic Sync

Seamlessly update spool data via the Bambuddy API for accurate tracking.

Scale Integration

Built-in scale support for precise remaining weight calculation.
