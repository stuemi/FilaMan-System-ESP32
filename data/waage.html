Waagen-Konfiguration

Verwalten und kalibrieren Sie Ihre eingebaute Waage für präzises Wiegen von Filament.

Aktionen

Kalibrierungsvorgang

Befolgen Sie diese Schritte sorgfältig, um die Genauigkeit sicherzustellen:

  1. Stellen Sie sicher, dass die Waage vollständig leer ist.
  2. Bereiten Sie ein 500g Kalibriergewicht vor.
  3. Klicken Sie unten auf "Kalibrierung starten".
  4. Schritt 1: Warten Sie auf die Nullpunktmessung.
  5. Schritt 2: Legen Sie das 500g-Gewicht auf die Waage, wenn Sie dazu aufgefordert werden.
  6. Schritt 3: Entfernen Sie das Gewicht.
